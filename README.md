# التخفيض الصح - Flutter Client

مشروع Flutter جديد مخصص لواجهة العميل فقط.

الهدف هو إعادة بناء التصميم والسلوك الفعليين للنسخة المبنية الحالية بدون نقل ملفات React القديمة.

API:
https://whats.alattab.site/takhfid/api/v4

راجع FLUTTER_CLIENT_SPEC.md قبل إضافة أي شاشة جديدة.

مبدأ مهم:
الخادم هو مصدر الحقيقة للكتالوج والمحتوى والحساب والطلبات. التخزين المحلي يستخدم للكاش والحالة الخفيفة فقط.

الفرع مصمم ليحتوي على ملفات المشروع الجديد فقط، ولا يعتمد على ملفات التطبيق القديم في شجرة العمل الحالية.
