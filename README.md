# تطبيق متجر التخفيض الصح للملابس الجاهزة 🛍️👗
### Al-Takhfeed Al-Sah E-Commerce Android & Web Application

تطبيق متجر إلكتروني متكامل وخفيف مصمم خصيصاً للتجارة الإلكترونية مع نظام دفع ومحافظ إلكترونية يمنية، تحكم إقليمي بأسعار الصرف لليمن (شمال وجنوب)، إدارة طلبات، محادثة فورية مع العملاء، تقارير مبيعات رسمية PDF معتمدة، وتطبيق أندرويد APK جاهز للبناء عبر **GitHub Actions**.

---

## 📱 ميزات التطبيق

1. **واجهة العميل وحساب الزائر:**
   - عرض صريح لاسم العميل المسجل تلقائياً عند تسجيل الدخول برقم الهاتف أو الحساب.
   - عرض صفة **"زائر"** بشكل أنيق واحترافي في حال التصفح بدون تسجيل دخول.
   - تخصيص أيقونة وصورة الملف الشخصي بأيقونات عصرية أو رفع صورة خاصة.

2. **نظام التسعير وأسعار الصرف بالمحافظات:**
   - دعم العملات: الريال اليمني (شمال / جنوب)، الريال السعودي (SAR)، الدولار الأمريكي (USD).
   - تحكم كامل بنسب الزيادة والتوصيل المجاني.

3. **تقرير المبيعات المعتمد (PDF & Share):**
   - إصدار تقارير مبيعات شاملة بالأصناف، والكميات، والباركود، وأرقام الطلبات.
   - تصفية حسب المحافظة والتواريخ.
   - تصدير فوري لملف PDF معتمد مع إمكانية المشاركة المباشرة عبر واتساب.

## 🚀 كيفية رفع المشروع إلى GitHub وبناء ملف APK تلقائياً

تم إعداد ملف **GitHub Actions Workflow** جاهز في المسار:
`.github/workflows/build-apk.yml`

عند رفع هذا المشروع إلى حسابك على **GitHub**، سيقوم GitHub تلقائياً بإنشاء وبناء ملف الـ **APK** دون الحاجة إلى تثبيت برامج على جهازك!

### خطوات الرفع لأول مرة:

1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub (مثلاً باسم: `altakhfeed-alsah-app`).
2. افتح موجه الأوامر (Terminal) في مجلد المشروع وقم بتنفيذ الأوامر التالية:

```bash
# 1. تهيئة مستودع Git
git init

# 2. إضافة جميع ملفات المشروع
git add .

# 3. حفظ التغييرات (Commit)
git commit -m "إطلاق تطبيق التخفيض الصح مع دعم بناء APK"

# 4. تحديد الفرع الرئيسي
git branch -M main

# 5. ربط المستودع بحسابك على GitHub (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/YOUR_USERNAME/altakhfeed-alsah-app.git

# 6. رفع الملفات إلى GitHub
git push -u origin main
```

---

## 📥 كيف تقوم بتحميل ملف الـ APK بعد الرفع؟

1. بعد تنفيذ `git push`، توجه إلى صفحة مستودعك على **GitHub**.
2. اضغط على تبويب **Actions** في أعلى الصفحة.
3. ستجد مهمة بعنوان **"Build Android APK"** قيد التنفيذ (تستغرق حوالي 2 إلى 3 دقائق).
4. عند اكتمال المهمة بنجاح (علامة صح خضراء ✅):
   - اضغط على اسم العملية.
   - في أسفل الصفحة في قسم **Artifacts**، ستجد ملفاً باسم:
     `Altakhfeed-AlSah-Android-APK`
   - اضغط عليه لتحميل ملف الـ **APK** مباشرة إلى هاتفك أو جهازك وتثبيته فوراً! 🎉

## 🛠️ البناء المحلي (Local Development & Android Studio)

إذا أردت تجربة التطبيق وبناء ملف الـ APK محلياً على جهازك:

```bash
# تثبيت الحزم
npm install

# بناء ملفات الويب
npm run build

# مزامنة الملفات مع مجلد أندرويد
npm run cap:sync

# فتح المشروع في Android Studio
npx cap open android
```
